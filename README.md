# Student Management System (Console-Based)

A modular, object-oriented console application written in Java to manage student records. This project demonstrates core Java capabilities, data structure management, and clean input validation techniques.

## 🚀 Features
* **Add Student**: Insert unique records with age and grade validation.
* **View Records**: Displays clean, tabular formatting using `System.out.printf`.
* **Search by ID**: Instantly retrieve individual profile objects using linear search algorithms.
* **Update Records**: Edit specific fields dynamically while preserving untouched data.
* **Delete Records**: Safe removal of specific student records from dynamic memory via index matching.

## 🛠️ Concepts Applied
* **Object-Oriented Programming (OOP)**: Class blueprints, encapsulation, constructors, getters/setters.
* **Java Collections Framework**: Dynamic data handling utilizing `ArrayList`.
* **Flow Control**: `do-while` menu loops, `switch-case` blocks, and nested `if-else` verification logic.
* **Robust Input Validation**: Defends against application crashes by matching `Scanner` data types using `.hasNextInt()`.

## 📋 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/punithta/Mini-Project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Mini-Project
   ```
3. Compile the Java source code files:
   ```bash
   javac Student.java StudentManagementSystem.java
   ```
4. Run the driver executable program:
   ```bash
   java StudentManagementSystem
   ```
